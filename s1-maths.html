第 5 題

解方程 3x − 5 = 16。請寫出計算過程及 x 的值。

查看解法與評分準則

3x = 16 + 5 = 21，所以 x = 21 ÷ 3 = 7。

  • 兩邊加 5，得到 3x = 21（1 分）
  • 兩邊除以 3，方法正確（1 分）
  • x = 7（1 分）

第 6 題

解方程 2(x − 3) = 10。請寫出計算過程及 x 的值。

查看解法與評分準則

兩邊除以 2，得到 x − 3 = 5；兩邊加 3，得到 x = 8。先展開括號的正確方法亦可。

  • 正確去括號，或兩邊除以 2（1 分）
  • 正確移項或加 3，得出 x 的值（1 分）
  • x = 8（1 分）

第 7 題

一個數的 3 倍比該數大 14。設該數為 n，列出方程並求 n 的值。

查看解法與評分準則

3n = n + 14，2n = 14，所以 n = 7。

  • 列出 3n = n + 14 或等值方程（1 分）
  • 正確化簡及解方程（1 分）
  • n = 7（1 分）

第 8 題

氣溫原為 −2°C，上升 5°C 後再下降 4°C。求最後氣溫，並寫出計算過程。

查看解法與評分準則

−2 + 5 − 4 = 3 − 4 = −1°C。

  • 以 −2 + 5 − 4 表示氣溫變化（1 分）
  • 運算過程正確，或清楚表達先升後降（1 分）
  • 最後氣溫為 −1°C（1 分）
